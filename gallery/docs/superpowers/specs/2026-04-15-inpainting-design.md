# AI 부분 보정 (인페인팅) 기능 설계

## 목적

갤러리 사진에서 그림을 추출한 후, 테두리에 남아있는 손가락이나 불필요한 요소를 클릭/드래그하여 주변 색상·질감과 자연스럽게 어우러지도록 AI로 보정한다.

## 핵심 요구사항

- 추출 결과 화면에서 "부분 보정" 버튼으로 인페인팅 모드 진입
- 드래그 페인팅으로 제거할 영역을 칠함 (빨간 마스크 표시)
- 슬라이더로 브러시 크기 조절 가능
- 마우스를 떼는 순간 LaMa AI가 해당 영역을 자동 보정 (1~3초)
- Undo 기능으로 보정 결과 되돌리기 가능

## 기술 스택

- **AI 엔진**: LaMa (Large Mask Inpainting) — CPU, 무료 오픈소스
- **백엔드**: Flask `/inpaint` API 엔드포인트
- **프론트엔드**: Canvas 기반 드래그 페인팅 + 마스크 생성

## 아키텍처

### UI 배치

- 기존 "수동 지정" 버튼 옆에 "부분 보정" 버튼 나란히 배치
- 인페인팅 모드 UI 구성: 브러시 크기 슬라이더 + Undo 버튼 + 캔버스

### 데이터 흐름

```
[프론트엔드]                    [백엔드]
Canvas 드래그 페인팅  ──POST──▶  /inpaint
  (이미지 + 마스크)              │
                                ├─ LaMa 모델 실행
빨간 마스크 표시                 │
  ↓ 마우스 업                   ◀── 보정된 이미지 반환
보정 결과 즉시 반영
  ↓ Undo 클릭 시
이전 상태로 복원 (히스토리 스택)
```

### API 설계

#### `POST /inpaint`

**요청:**
- `image`: 현재 이미지 (base64 또는 파일)
- `mask`: 마스크 이미지 (흑백 PNG, 흰색=보정 영역)

**응답:**
- `result_url`: 보정된 이미지 URL
- `result_image`: 보정된 이미지 (base64)

### 프론트엔드 상세

#### 인페인팅 모드 진입/퇴장
1. "부분 보정" 버튼 클릭 → 인페인팅 캔버스 표시
2. 현재 처리된 이미지가 캔버스에 로드됨
3. 보정 완료 후 "완료" 버튼으로 모드 종료

#### 드래그 페인팅
- 마우스 다운 → 드래그 → 빨간색 반투명 마스크로 영역 표시
- 커서는 현재 브러시 크기의 원형으로 표시
- 마우스 업 → `/inpaint` API 호출 → 로딩 스피너 → 결과 반영

#### 브러시 크기 조절
- range 슬라이더 (최소 5px ~ 최대 100px, 기본 30px)
- 슬라이더 옆에 현재 크기 숫자 표시

#### Undo
- 보정 전 이미지를 JavaScript 배열(스택)에 저장
- Undo 버튼 클릭 시 이전 상태로 복원
- 여러 번 Undo 가능 (스택 깊이만큼)

### 백엔드 상세

#### LaMa 모델 로드
- 앱 시작 시 LaMa 모델 1회 로드 (rembg와 동일 패턴)
- `simple_lama` 패키지 사용 (`pip install simple-lama-inpainting`)

#### 인페인팅 처리
1. 요청에서 이미지 + 마스크 수신
2. LaMa 모델에 입력하여 인페인팅 수행
3. 결과 이미지를 processed 폴더에 저장 + base64로 응답

## 테스트 계획

- 단위 테스트: 인페인팅 함수가 마스크 영역을 올바르게 처리하는지
- 통합 테스트: `/inpaint` API 엔드포인트 정상 동작
- 수동 테스트: 실제 갤러리 사진에서 손가락 제거 품질 확인
