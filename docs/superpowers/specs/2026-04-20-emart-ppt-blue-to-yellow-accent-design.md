# EMART 사업제안서 PPT — 파랑 → 노랑+검정테두리 (A안 보존형)

- 작성일: 2026-04-20
- 상태: 승인됨
- 사용자 결정: A안 (원본 흰 배경 유지, 파란색 강조만 노랑+검정 테두리로 교체)

## 배경

`EMART/이마트에브리데이 사업제안서_260301.pptx` 는 이마트 에브리데이 사업제안용 PPT.
기존 `restyle_ppt.py` 는 "검정 배경 전면 리스타일 + 이마트 프레임/페이지번호 추가" 방식이었으나
사용자 평가 결과 마음에 들지 않아 v2 결과물을 삭제. 새로운 보존형 접근 필요.

## 목표

원본의 흰색 베이스 레이아웃/텍스트 배치는 그대로 유지하고, **파란색 계열 강조(채움/라인) 만** 이마트 브랜드 톤(노랑 + 검정 테두리)으로 치환한다.

## 비목표 (NOT this time)

- 슬라이드 배경 검정화 없음
- 이마트 프레임/좌측 세로바/상단띠/페이지번호 추가 없음
- 이미지 · 로고 · 텍스트 레이아웃 건드리지 않음
- 새로운 도형 추가 없음 (테두리 속성 추가는 예외)

## 입출력

| 항목 | 값 |
|---|---|
| 입력 | `EMART/이마트에브리데이 사업제안서_260301.pptx` |
| 출력 | `EMART/이마트에브리데이_사업제안서_v3_260301.pptx` |
| 구현 | `EMART/restyle_ppt_v3.py` (기존 `restyle_ppt.py` 는 보존) |

## 색상 매핑

원본 파란 계열은 모두 **동일 강조 강도의 노랑** 으로 통일 (연블루 → 연노랑 구분 없음).

| 원본 HEX | 의미 | 변환 후 Fill | 변환 후 Line |
|---|---|---|---|
| `#002B5B` | 네이비 강조 블록 | `#FFD200` (YELLOW) | `#151515` (BLACK) 1.25pt |
| `#1F6BBA` | 블루 강조 | `#FFD200` | `#151515` 1.25pt |
| `#74A9D8` | 연블루 보조 | `#FFD200` | `#151515` 1.25pt |

**라인 색 전용 매핑 (도형 자체의 외곽선 색)**
- `#002B5B`, `#1F6BBA`, `#74A9D8` → `#151515` (검정)
- 기타 회색 라인은 원본 유지

## 텍스트 규칙 (가독성 보정)

원칙: **원본 텍스트 색 유지**. 아래 케이스만 예외적 보정.

| 상황 | 원본 텍스트 색 | 변환 후 |
|---|---|---|
| 파랑 블록 (fill 변경됨) 위의 **흰색 텍스트** | `#FFFFFF` | `#151515` (노랑 위에서 안 보이므로 검정화) |
| 파랑 블록 (fill 변경됨) 위의 그 외 텍스트 | 나머지 | 원본 유지 |
| 파랑 블록이 아닌 셰이프의 텍스트 | 모두 | 원본 유지 (파란 텍스트 `#1F6BBA` 포함) |

파랑 텍스트 자체는 원본 유지 (흰 배경 위에서는 파란 텍스트가 가독성 OK).

## 표(Table) 규칙

셀 레벨에도 동일한 Fill/Line/Text 규칙 적용:
- 셀 fill이 파란 계열 → 노랑 + 셀 테두리 검정
- 셀 안 흰 텍스트 (파랑 셀이었던 경우) → 검정으로 교체
- 그 외 셀 텍스트는 원본 유지

## 차트 규칙

- 파랑 시리즈 (라인 / 마커 / 막대 fill) → 노랑 `#FFD200` 으로 교체
- 차트 배경, 축 레이블, 데이터 레이블 색은 **건드리지 않음** (원본 유지)
- 차트 테두리 추가 없음

## 그룹 셰이프

- 그룹(shape_type == 6)은 평탄화하여 내부 셰이프까지 재귀 처리

## 검증 방법

1. 스크립트 실행 후 출력 파일 생성 확인
2. 원본/신규 파일 크기 비교 (크게 차이 없어야 함, 구조 보존 증거)
3. 파워포인트로 열어 슬라이드 1~5 장 및 마지막 장 육안 확인:
   - 흰 배경 유지됨
   - 과거 파란 블록이 노랑 + 검정 테두리로 바뀜
   - 파란 블록 안에 있던 흰 텍스트가 검정으로 바뀌어 읽힘
   - 다른 텍스트 색 변함 없음
   - 이미지 · 로고 그대로

## 롤백
