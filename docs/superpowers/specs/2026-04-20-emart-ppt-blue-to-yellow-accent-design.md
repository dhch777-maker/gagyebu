# EMART 사업제안서 PPT — 파랑 → 노랑+검정테두리 (A안 보존형)

- 작성일: 2026-04-20
- 상태: 승인됨
- 사용자 결정: A안 (원본 흰 배경 유지, 파란색 강조만 노랑+검정 테두리로 교체)

## 배경

`EMART/이마트에브리데이 사업제안서_260301.pptx` 는 이마트 에브리데이 사업제안용 PPT.
기존 `restyle_ppt.py` 는 "검정 배경 전면 리스타일 + 이마트 프레임/페이지번호 추가" 방식이었으나
사용자 평가 결과 마음에 들지 않아 v2 결과물을 삭제. 새로운 보존형 접근 필요.

## 목표

원본의 흰색 베이스 레이아웃/텍스트 배치는 그대로 유지하고, **파란색 계열 강조(채움/라인) 만** 이마트 브랜드 톤(노랑 + 검정 테두리)으로 치환한다.

## 비목표 (NOT this time)

- 슬라이드 배경 검정화 없음
- 이마트 프레임/좌측 세로바/상단띠/페이지번호 추가 없음
- 이미지 · 로고 · 텍스트 레이아웃 건드리지 않음
- 새로운 도형 추가 없음 (테두리 속성 추가는 예외)

## 색상 매핑

원본 파란 계열은 모두 **동일 강조 강도의 노랑** 으로 통일 (연블루 → 연노랑 구분 없음).

| 원본 HEX | 의미 | 변환 후 Fill | 변환 후 Line |
|---|---|---|---|
| `#002B5B` | 네이비 강조 블록 | `#FFD200` (YELLOW) | `#151515` (BLACK) 1.25pt |
| `#1F6BBA` | 블루 강조 | `#FFD200` | `#151515` 1.25pt |
| `#74A9D8` | 연블루 보조 | `#FFD200` | `#151515` 1.25pt |

**라인 색 전용 매핑 (도형 자체의 외곽선 색)**
- `#002B5B`, `#1F6BBA`, `#74A9D8` → `#151515` (검정)
- 기타 회색 라인은 원본 유지

## 텍스트 규칙 (가독성 보정)

원칙: **원본 텍스트 색 유지**. 단, 아래 두 예외 적용.

| 상황 | 원본 텍스트 색 | 변환 후 |
|---|---|---|
| 파랑 블록 (fill 변경됨) 위의 **흰색 텍스트** | `#FFFFFF` | `#151515` (노랑 위에서 안 보이므로 검정화) |
| **파란 계열 텍스트** (전 셰이프 대상) | `#002B5B`, `#1F6BBA` 등 "B 우위" 색 | `#151515` |
| 그 외 텍스트 | 검정/회색/흰색 등 | 원본 유지 |

**파란 텍스트 판정**: 단순 HEX 매칭이 아니라 휴리스틱(`B > R + 20 AND B > G + 20 AND B ≥ 80`)으로 모든 파란 계열을 탐지. 사용자 피드백: "안 바뀐 파란 계열은 다 검정으로." (2026-04-20)

## 표(Table) 규칙

셀 레벨에도 동일한 Fill/Line/Text 규칙 적용:
- 셀 fill이 파란 계열 → 노랑 + 셀 테두리 검정
- 셀 안 흰 텍스트 (파랑 셀이었던 경우) → 검정으로 교체
- 그 외 셀 텍스트는 원본 유지

## 노란 배경 위 흰 글씨 규칙

같은 셰이프의 fill 이 노랑으로 바뀌었을 때 그 안 흰 글씨는 이미 검정으로 교체했지만, **별도 텍스트박스가 노란 바 위에 올라간 케이스**(예: 2p "점포에 다시 방문할 이유를 만드는 구조가 필요합니다.")는 그 규칙을 빠져나간다.

규칙 추가:
- 셰이프 bbox 가 노란 fill 셰이프 bbox 와 **≥50% 겹치고**, 그 셰이프 자신의 fill 은 노랑이 아닐 때
- 해당 셰이프 안의 **흰 텍스트 run** 에 **검정(#151515) 0.75pt 아웃라인** 추가 (흰 글씨는 유지)
- OOXML 레벨: `a:rPr` 의 첫 자식으로 `a:ln` 삽입 (스키마상 ln 이 solidFill 앞)

사용자 피드백: "노란 박스 안 하얀 글씨가 안 보인다. 글씨 테두리 검정으로." (2026-04-20)

## 아이콘 크기·종횡비 규칙

원본에서 아이콘이 1:1 정사각형 프레임에 박혀 있어 지도핀 같이 세로가 긴 아이콘이 옆으로 찌그러짐. 그리고 8~14p 는 아이콘이 노란 원을 80~85%로 꽉 채움.

규칙:
- 모든 PICTURE 에 대해 **중심을 포함하는 가장 작은 노란 셰이프**를 컨테이너로 판정
- 컨테이너가 있으면:
  - `current_occupy = max(pw/cw, ph/ch)`
  - `target_occupy = min(current_occupy, 0.60)` — 이미 여유 있으면 유지, 꽉 차면 60% 로 축소
  - 원본 PNG 종횡비(`iw/ih`)에 맞게 축약해 target 박스 안에 fit, 컨테이너 중앙 정렬
  - 변화가 ≤2% 면 스킵
- 컨테이너가 없으면 손대지 않음 (사진·로고 보호)

효과: 3/5/7p 는 그대로, 8~14p 는 60%로 축소. 지도핀(native 0.75) 의 옆으로 벌어진 찌그러짐 해소.

사용자 피드백: "8p, 9~13p 아이콘이 노란 원에 너무 꽉 참. 지도핀은 옆으로 벌어져 찌그러진 느낌." (2026-04-20)

## 아이콘(PNG) 규칙

본문에 삽입된 아이콘은 대부분 단색 파란 실루엣 PNG 이미지. python-pptx로 도형 색은 못 바꿔도 PNG blob을 Pillow로 직접 픽셀 치환 가능.

- `prs.part.package.iter_parts()` 로 모든 `image/png` 파트 순회
- 가드: 파란 픽셀 ≥ 5% AND 그 외 불투명 픽셀 < 5% (= 단색 아이콘)
- 매칭 시 파란 픽셀의 RGB만 `#151515` 로 교체, 알파 유지 → 가장자리 자연스러움
- 사진 같은 복합 이미지는 자동 스킵

사용자 피드백: "3p 사람 3명 아이콘 등 파란 아이콘도 검정으로." (2026-04-20)

## 차트 규칙

- 파랑 시리즈 (라인 / 마커 / 막대 fill) → 노랑 `#FFD200` 으로 교체
- 차트 배경, 축 레이블, 데이터 레이블 색은 **건드리지 않음** (원본 유지)
- 차트 테두리 추가 없음

## 그룹 셰이프

- 그룹(shape_type == 6)은 평탄화하여 내부 셰이프까지 재귀 처리

## 검증 방법

1. 스크립트 실행 후 출력 파일 생성 확인
2. 원본/신규 파일 크기 비교 (크게 차이 없어야 함, 구조 보존 증거)
3. 파워포인트로 열어 슬라이드 1~5 장 및 마지막 장 육안 확인:
   - 흰 배경 유지됨
   - 과거 파란 블록이 노랑 + 검정 테두리로 바뀜
   - 파란 블록 안에 있던 흰 텍스트가 검정으로 바뀌어 읽힘
   - 다른 텍스트 색 변함 없음
   - 이미지 · 로고 그대로
