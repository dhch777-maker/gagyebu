# 이마트 에브리데이 사업제안서 PPT 리브랜딩 디자인 스펙

- 작성일: 2026-04-19
- 대상 파일: `EMART/이마트에브리데이 사업제안서_260301.pptx` (원본 유지)
- 산출 파일: `EMART/이마트에브리데이_사업제안서_v2_260301.pptx`
- 발표 대상: 이마트 에브리데이 (내부 경영·실무진)

## 1. 목표

일반 사업제안서 톤의 기존 14장 PPT를, "이마트 에브리데이 내부인이 봤을 때 '이건 우리랑 찰떡이다'라고 느낄 만큼 브랜드 톤에 밀착된 제안서"로 전면 리브랜딩한다.

## 2. 컨셉 결정사항 (브레인스토밍 합의)

| 축 | 선택 |
|---|---|
| 변화 범위 | D. 풀옵션 (비주얼 + 카피 + 스토리 + 브랜드 무드 연출) |
| 비주얼 코드 | C. 이마트 에브리데이 공식 브랜드 톤 오마주 |
| 키메시지 프레임 | D. 동네·이웃 (감성) + 장바구니·매대 (실무) 듀얼 프레임 |
| 이미지 채움 방식 | D. 플랫 아이콘+컬러블록 기본 + 감성 포인트만 실사풍 |

## 3. 비주얼 아이덴티티

### 컬러 팔레트
- **Primary Red**: `#E60012` (이마트 에브리데이 레드)
- **Accent Yellow**: `#FFD200` (이마트 옐로우 헤리티지)
- **Dark**: `#1A1A1A` (텍스트·고대비)
- **Mid Gray**: `#666666` (서브 텍스트)
- **Light Gray**: `#F5F5F5` (배경 블록)
- **White**: `#FFFFFF`

### 타이포그래피
- 제목: Pretendard Bold / 32~44pt
- 부제: Pretendard SemiBold / 18~22pt
- 본문: Pretendard Regular / 12~16pt
- 숫자 강조: Pretendard ExtraBold / 48~72pt + 레드 컬러

### 레이아웃 원칙
- 좌측 세로 레드 컬러바 (4pt)
- 상단 헤드라인 고정, 넓은 상하 여백
- 컬러블록은 레드/옐로우/그레이 3단계만 사용
- 숫자는 항상 크고 굵게, 단위는 작게

## 4. 이중 톤 구조

### 감성 파트 (표지·간지·마무리)
- 슬라이드 1, 14 및 필요시 간지
- 동네·이웃 프레임
- 실사풍 매장/동네 이미지 풀블리드 + 하단 반투명 레드 컬러바
- 헤드라인 볼드·크게

### 실무 파트 (본문 데이터·운영)
- 슬라이드 2~13
- 장바구니·매대 프레임
- 플랫 아이콘 + 컬러블록 + 수치 강조
- 차트/테이블 데이터는 원본 그대로 유지, 스타일만 리스킨

## 5. 14장 슬라이드별 재설계

| # | 원본 헤드라인 | 리뉴얼 헤드라인 | 주요 변경 |
|---|---|---|---|
| 1 | 지역 기반 공동구매 물류 거점 제안 | **매일, 동네가 모이는 거점** | 표지 감성 리뉴얼. 실사풍 이미지 + 메인 카피 + 서브 카피 |
| 2 | 오프라인 점포 매출 환경 변화 | **오프라인이 흔들리는 시간** | 차트 스타일 리스킨, 데이터 유지 |
| 3 | 지역 공동구매 수령 거점 모델 | **매대 옆, 수령대 하나** | 4단계 플로우 플랫 아이콘화 |
| 4 | 점포에 제공되는 직접 수익 | **고정비 0원, 수수료 5%** | 5% 숫자 초대형 강조, 차트/테이블 스타일 리스킨 |
| 5 | 점포 방문 증가 효과 | **한 번의 장바구니, 두 번의 방문** | 3컷 카드 레이아웃 |
| 6 | 기존 공동구매 모델과의 차이 | **동네마트만 할 수 있는 일** | 비교표 리디자인, 레드/그레이 대비 |
| 7 | 소비자 참여 프로세스 | **온라인에서 매장까지, 5단계** | 5단계 가로 플로우 |
| 8 | 공동구매 상품 전략 | **대형마트엔 없는 상품만** | 2x2 그리드 카드 |
| 9 | 운영 프로세스 | **점주는 확인만, 수익은 자동** | 4단계 가로 플로우 |
| 10 | 점포 부담 최소화 설계 | **점주를 귀찮게 하지 않는 설계** | 4개 아이콘 카드 |
| 11 | 파일럿 운영 제안 | **3개월, 5개 점포로 증명** | 숫자 4박스 강조 |
| 12 | 기대 효과 | **점포에 남는 것, 다섯 가지** | 5개 카드 가로 배열 |
| 13 | 리스크 대응 방안 | **잘못돼도 점포는 손해 없음** | 4개 아이콘 카드 |
| 14 | 이마트 에브리데이와의 협력 제안 | **에브리데이에 가장 잘 어울리는 제안** | 마무리 감성 리뉴얼, 4포인트 요약 + 클로징 |

## 6. 구현 방식

- 도구: `python-pptx`
- 원본 파일은 건드리지 않고 신규 파일로 저장
- 차트/테이블 데이터는 원본에서 추출해 그대로 재주입 (수치 무결성 보장)
- 이미지는 다음 우선순위로 처리:
  1. 감성 파트: Unsplash/Pexels 무료 라이선스 실사풍 이미지 (한국 마트/장바구니/동네 무드)
  2. 실무 파트: 통일된 플랫 아이콘 (SVG → 임베드) 또는 Unicode 심볼 + 컬러블록
- 한글 서체는 시스템에 있는 Pretendard, 없으면 맑은 고딕으로 폴백
