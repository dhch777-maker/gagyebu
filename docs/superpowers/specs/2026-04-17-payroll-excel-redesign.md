# 분트 미술학원 인건비 엑셀 고도화 설계

## 개요

기존 `분트 재무제표(25.12월).xlsb`의 인건비 계산 시트(탭9)를 독립 `.xlsx` 파일로 재설계한다.
월별 블록 반복 구조를 단일 테이블 구조로 전환하여, 입력 편의성/시각적 완성도/자동화를 개선한다.

## 현재 문제점

1. **반복 작업**: 매달 새 블록(약 45행)을 복사해서 생성
2. **입력 오류**: 근무자명 직접 타이핑 → 오타 발생
3. **수동 계산**: 3.3% 원천징수, 실지급액, 원장급여를 매번 수동 산출
4. **탐색 어려움**: 11개월 데이터가 한 시트 540행에 세로로 나열
5. **월급/시급 혼재**: 고경민(월급제)과 시급제 직원의 계산 로직이 암묵적

## 설계

### 파일 형식

- 출력: `BUNT_finance/분트_인건비관리.xlsx`
- 기존 xlsb 파일은 변경하지 않음 (보존)
- Python openpyxl로 생성

### 시트 구성 (3개)

#### 1. 직원 마스터

직원 원본 정보를 한 곳에서 관리한다.

| 열 | 헤더 | 데이터 유형 | 비고 |
|----|------|-------------|------|
| A | 이름 | 텍스트 | |
| B | 급여유형 | 드롭다운: 월급/시급 | 데이터 유효성 검사 |
| C | 금액 | 숫자 | 월급제: 월급액, 시급제: 시급 |
| D | 입금계좌 | 텍스트 | 은행+계좌번호 |
| E | 재직상태 | 드롭다운: 재직/퇴직 | |
| F | 입사일 | 날짜 | |
| G | 비고 | 텍스트 | |

마이그레이션 대상 직원 (6명):
- 고경민: 월급, 1,200,000원, 국민은행 82240104164295
- 장예원: 시급, 12,000원, 카카오뱅크 3333-07-7072641 (초기: 신한은행 110-411-451217)
- 유은비: 시급, 12,000원, 우리 1002-533-898534
- 전민아: 시급, 12,000원, 하나은행 558-910330-30707
- 김채현: 시급, 12,000원, 우리은행 1002-351-542250
- 이진화: 시급, 12,000원, 우리은행 1002-166-678383

#### 2. 근무 기록

일별 출퇴근 데이터를 단일 테이블로 누적 기록한다.

| 열 | 헤더 | 데이터 유형 | 비고 |
|----|------|-------------|------|
| A | 날짜 | 날짜 | |
| B | 근무자 | 드롭다운 | 직원 마스터의 재직자만 표시 |
| C | 시작시간 | 숫자 | 예: 14.5 = 오후 2:30 |
| D | 종료시간 | 숫자 | 예: 18.5 = 오후 6:30 |
| E | 근무시간 | 수식 | =D-C |
| F | 일 급여 | 수식 | 시급제: 근무시간×시급, 월급제: 빈칸 |
| G | 급여유형 | 수식 | VLOOKUP으로 마스터 참조 |
| H | 비고 | 텍스트 | 자유 입력 |

설계 원칙:
- 휴무일은 입력하지 않음 (빈 행 제거)
- 엑셀 테이블(ListObject) 서식 적용 → 행 추가 시 수식 자동 확장
- 기존 xlsb 2월~11월 데이터를 파싱하여 자동 마이그레이션
- 날짜 오름차순 정렬

#### 3. 급여 요약

월 선택 시 해당월 급여를 자동 집계한다.

**상단: 월 선택**
- B1 셀: 드롭다운으로 연월 선택 (202501~202512)

**직원별 급여표 (A4~ 영역):**

| 열 | 헤더 | 계산 방식 |
|----|------|-----------|
| A | 이름 | 마스터 재직자 목록 |
| B | 급여유형 | 마스터 연동 |
| C | 총 근무시간 | SUMIFS(근무기록!E열, 근무기록!B열=이름, 근무기록!A열>=해당월1일, 근무기록!A열<=해당월말일) |
| D | 총 급여(세전) | 월급제: 고정금액 / 시급제: 총근무시간×시급 |
| E | 3.3% 원천징수 | =D×0.033 |
| F | 실지급액 | =D-E |
| G | 입금계좌 | 마스터 연동 |
| H | 지급여부 | 드롭다운: O/X |

**하단 요약:**
- 직원 급여 합계
- 당월 총 인건비

### 시각 디자인

| 요소 | 스타일 |
|------|--------|
| 헤더 행 | 진한 남색 배경 (#1F4E79) + 흰 글자, 굵게 |
| 입력 셀 | 연한 노란 배경 (#FFF2CC) |
| 자동계산 셀 | 연한 회색 배경 (#F2F2F2) + 셀 보호 |
| 금액 서식 | #,##0 (천단위 쉼표) |
| 조건부 서식 | 지급여부 O → 초록 글자, X → 빨강 글자 |
| 테이블 | 줄무늬(밝은/어두운 교대), 자동 필터 |
| 열 너비 | 내용에 맞게 최적화 |
| 시트 탭 색상 | 마스터: 파랑, 근무기록: 초록, 급여요약: 주황 |

### 데이터 마이그레이션

Python으로 기존 xlsb 파싱:
1. 11개 월별 블록(R2~R540)에서 근무 기록 추출
   - 날짜(엑셀 시리얼) → datetime 변환
   - 근무자명, 시작/종료시간 추출
   - "휴무" 행은 건너뜀
2. 급여 요약 영역에서 직원별 계좌 정보 추출 → 마스터 생성
3. 지급여부(O) 데이터 보존

### 범위 외 (Out of Scope)

- 기존 xlsb 파일 수정
- 다른 탭(결산 보고서, 총괄 등)과의 연동
- VBA 매크로
- 원장급여 자동 산출 (매출/운영비 데이터가 별도 시트에 있으므로 향후 통합 시 추가)
